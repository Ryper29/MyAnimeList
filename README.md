# MyAnimeList Custom CSS — Warm Editorial Dark

Koleksi **Custom CSS** pribadi untuk tampilan **MyAnimeList (Modern List)** dengan tema utama **Warm Editorial Dark** — gaya tabel editorial gelap yang bersih, hangat, dan nyaman dibaca.

## Fitur Utama (`MyAnimeList.css`)

- **Editorial Dark Table**: palet gelap dengan aksen *warm amber* (`#e0a458`), tipografi `Newsreader` + `Plus Jakarta Sans`, dan angka rata (`tabular-nums`).
- **Indikator Status Semantik**: garis tipis `3px` di tepi kiri tiap baris (Watching/Reading, Completed, On Hold, Dropped, Plan to Watch/Read).
- **Mendukung Anime & Manga List**: styling penuh untuk kolom *Progress* (episode) maupun *Chapters* & *Volumes*.
- **Sticky Navigation & Quick-Edit**: bar navigasi menempel saat scroll, serta form *quick-edit* (skor, episode, catatan) dan bingkai modal *Edit* yang menyatu dengan tema gelap.
- **Responsif**: menyesuaikan ukuran layar sempit dan perangkat sentuh.

## Struktur File

```text
.
├── MyAnimeList.css              # Tema utama aktif (Warm Editorial Dark)
└── archive/
    ├── MyAnimeList.css          # Arsip: Simple Purple (Table)
    └── MyAnimeList(1).css       # Arsip: Ultra Minimal Dark (Card Grid)
```

## Cara Pakai

1. Buka [MyAnimeList List Style Design](https://myanimelist.net/ownlist/style/theme/1) (pastikan memakai **Modern List**).
2. Salin seluruh isi file `MyAnimeList.css`.
3. Tempel ke kolom **Add Custom CSS**, lalu klik **Save**.

> **Catatan**: Custom CSS MyAnimeList secara default hanya tampil di **Desktop Web** (PC/laptop, atau browser HP dengan mode *Desktop Site*). Aplikasi mobile MAL dan tampilan mobile web bawaan tidak memuat Custom CSS.
